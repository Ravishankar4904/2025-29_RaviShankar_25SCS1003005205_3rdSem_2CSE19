## 📌 Overview

This repository contains the four console-based C++ applications built during a one-month, project-based C++ Programming Internship. The projects progress from structures and file handling, through object-oriented design, to interactive program logic — covering the core workflow of C++ application development.

## 🛠️ Tech Stack

- **Language:** C++ (structures, classes, functions, control flow)
- **Paradigm:** Object-Oriented Programming (classes, objects, encapsulation)
- **Persistence:** File handling via `fstream`
- **Data Structures:** Arrays and structured records
- **Tools:** GCC / Code::Blocks / Dev-C++

## 📂 Modules

| # | Module | Key Concepts |
|---|--------|---------------|
| 1 | **Student Management System** | Structures/classes, file handling, menu-driven CRUD, input validation |
| 2 | **Bank Management Application** | OOP (Account class), deposit/withdraw/balance-check, secure file storage |
| 3 | **Library Management System** | Book/Member structures, issue/return workflow, search by title/author |
| 4 | **Mini Game (Tic Tac Toe / Snake)** | 2D arrays, game loop, win/loss detection, replay handling |

### 1. Student Management System
Add, update, delete and display student records with data persisted to disk using `fstream`, wrapped in a menu-driven console interface with input validation.

### 2. Bank Management Application
An `Account` class encapsulating customer data, with deposit, withdrawal, and balance-check operations, validated against edge cases like insufficient balance and invalid account numbers.

### 3. Library Management System
Tracks books and members, supports issue/return workflows, and allows searching the catalogue by title or author, with all records persisted between sessions.

### 4. Mini Game Project
A console-rendered game board using arrays, with turn-based logic, win/loss/draw detection, and a replay option — without needing to relaunch the program.

## 🚀 Getting Started

```bash
# Compile any module (example: Student Management System)
g++ student_management.cpp -o student_management

# Run
./student_management
```
